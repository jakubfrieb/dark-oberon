    How to join a game

    1. Copy the game's address from this page (the host can also send it to you).
    2. In Dark Oberon choose Play, then Connect. Paste the whole address, including the port after the colon, into the IP field, type your name and confirm.
    3. Pick your race and colour. Every player needs a different one. Add computer fills free slots with CPU players.
    4. Click Play in the game to start. The host can also press Start game here.
